# Local AI Reference 0.12.1

This update makes the local SME demos easier to understand before any skill or
real company data is used.

- A new **Help > SME use cases** window explains all eight examples in plain
  language: the business problem, expected input, reviewable result, and where
  a separately approved production connector is still required.
- Skill Studio includes a question-mark action beside the Demo Portfolio, so
  the guide is available directly where a demo is selected.
- A standalone static HTML overview is bundled with the app. It works without a
  server and contains no scripts, analytics, remote fonts, images, or remote
  stylesheets.
- Both help surfaces state clearly that the demos use synthetic data and that
  viewing or importing one does not load a model, start a tool, contact a
  server, install a skill, or write to a production system.

The underlying eight deterministic Golden Paths and their privacy boundaries
are unchanged from 0.12.0.
